# GitHub Discussions / GitHub 讨论

[Documentation index / 文档索引](../README.md) · [Website mission / 网站使命](../../README.md)

Every article has a discussion section and a floating composer, using giscus to authenticate GitHub visitors and publish to `DapengFeng/dapengfeng.github.io`. Each article has one thread in the General category. Comments, questions, and ideas all belong to that conversation. Each thread is created on its first comment or reaction, not when someone reads the page. Replies and reactions then stay in that thread. This does not create a separate GitHub discussion for every message.

每篇文章自动包含文末讨论区与浮动输入面板，通过 giscus 为 GitHub 访客登录并发表到 `DapengFeng/dapengfeng.github.io`。每篇文章只有一个话题，统一进入 General 分类，评论、提问与想法都在同一处交流。首次发言或表态时才创建对应话题，阅读页面不会创建；之后的回复与表态保留在该话题中，不会为每条留言创建新 Discussion。

**One-time setup:** install the [giscus GitHub App](https://github.com/apps/giscus) for this repository only. Discussions is already enabled and the public repository/category IDs are configured in `scripts/discussions.mjs`. Push and deploy the code, including the root `giscus.json`, then verify GitHub sign-in and a real submission yourself. No PAT, OAuth client secret, Actions secret, or additional application server is needed. Discussions appear below the article. Connection errors offer an inline reload action without directing readers to GitHub.

**一次性配置**：安装 [giscus GitHub 应用](https://github.com/apps/giscus)，仅授权本仓库。仓库已开启 Discussions，公开的仓库与分类 ID 已写入 `scripts/discussions.mjs`。推送并部署代码（包括仓库根目录的 `giscus.json`）后，可用自己的 GitHub 账号验证登录和实际发表。无需配置 PAT、OAuth 密钥、Actions Secret 或额外应用服务器。讨论直接显示在文章下方。连接失败时提供站内重新加载操作，不引导读者跳转到 GitHub。

The floating launcher uses a speech-bubble icon with a localized accessible name. The inline and floating panels use GitHub-style dark surfaces and borders; giscus supplies the comment editor, replies, reactions, and sign-in UI with a local dark theme (`src/styles/giscus-theme.css`). The theme hides only the widget’s “powered by giscus” attribution; it preserves reader content and bundles the upstream palette with its MIT license. Loading uses a spinner with screen-reader status, and failures retain an explanation and an icon-only retry button.

浮动入口使用对话气泡图标，并提供双语可访问名称。文末和浮动面板采用 GitHub 风格的深色背景与边框；评论编辑器、回复、表态及登录界面由 giscus 提供，采用本地深色主题（`src/styles/giscus-theme.css`）。主题仅隐藏组件的“由 giscus 提供支持”署名，保留读者内容，并随上游配色保留 MIT 许可证。加载时显示转圈图标与供屏幕阅读器读取的状态，失败时保留原因说明及图标式重试按钮。

Thread mapping uses the article URL with giscus strict matching. The internal ` · comment` suffix preserves the original Comments identity; it is not a reader-facing category. Legacy `?discussion=comment`, `?discussion=idea`, and `?discussion=discussion` links open this single thread. Renaming a title or switching languages keeps the same thread; changing the published URL changes its mapping. New articles require no manual thread setup. Discussions created manually on GitHub are not matched by loose title similarity: to connect an existing thread, its category and SHA-1 mapping marker must match the term generated by `discussionTerm()` (see [giscus strict matching](https://github.com/giscus/giscus/blob/main/ADVANCED-USAGE.md#data-strict)).

话题按文章 URL 关联，并启用 giscus 严格匹配。内部保留 ` · comment` 后缀以沿用原 Comments 话题标识，不再作为读者可选分类。旧的 `?discussion=comment`、`?discussion=idea` 和 `?discussion=discussion` 链接均打开这个统一话题。改标题、切换语言不会更换话题；更改已发布 URL 会改变关联。新文章无需手动创建讨论。在 GitHub 手动创建的话题不会按相似标题自动混入；如需关联旧话题，其分类和 SHA-1 标记必须与 `discussionTerm()` 生成的标识一致，参见 [giscus 严格匹配说明](https://github.com/giscus/giscus/blob/main/ADVANCED-USAGE.md#data-strict)。

Article pages preconnect to giscus. The article’s thread warms during idle time after the page loads, when readers approach the footer, or when they hover or focus the discussion controls. Save-Data and 2G connections skip speculative loading. The initial iframe URL selects its language; a language message is sent only when that locale actually changes. Moving between the inline and floating view keeps the same mounted editor and its draft. Reloading/navigating away does not preserve drafts. Site controls follow the language selection; the GitHub widget uses Chinese in Chinese mode and English otherwise. Reader posts remain in their original language. The integration checks both message origin and iframe identity. `npm run test:discussions` uses a mock widget and never publishes to GitHub.

文章页提前与 giscus 建立连接；页面加载后在空闲时、接近文末时，或讨论控件悬停与获得焦点时，预加载文章话题。省流量模式与 2G 连接跳过预加载。组件初始 URL 已包含语言，只有实际语言变化时才发送切换消息。文末与浮动视图之间切换，保留同一个输入区与草稿；刷新或离开页面不保留草稿。本站控件遵循语言选择；GitHub 组件在中文模式使用中文，其他模式使用英文，读者留言保留原语言。接入代码同时检查消息来源域名与 iframe 身份。`npm run test:discussions` 使用模拟组件，不会向 GitHub 发表内容。
