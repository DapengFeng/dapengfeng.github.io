A complete editable program 可编辑的完整程序

Add data-godbolt="c++" only to a complete program supported by the configured compiler. Readers can edit, reset, compile, and run it here. Diagnostics, stdout, and stderr appear separately. This example prints 13; it makes no performance claim. 只有当前配置的编译器支持的完整程序才添加 data-godbolt="c++"。读者可以在文内修改、重置、编译和运行，编译诊断、标准输出与标准错误会分别展示。本例输出 13，不代表性能测试结果。 

#include <array>
#include <iostream>

int main() {
    const std::array<double, 2> x{2.0, 3.0};
    double squared_length = 0.0;
    for (const double value : x) {
        squared_length += value * value;
    }
    std::cout << squared_length << '\n';
    return squared_length == 13.0 ? 0 : 1;
}
